# 数值工坊

用于检查挂机游戏战斗、升级成本、资源收入与长期推进的浏览器工具。填写游戏数据后，可以查看能否通关、卡在哪里、需要等待多久，并比较参数调整带来的改善与代价。

## 直接使用

1. 点击本页 **Code → Download ZIP**，下载后解压整个文件夹。
2. 用 Chrome 或 Edge 打开 `dist/index.html`。
3. 从双方战斗数据开始，按需要补充成长、升级、收入和上线安排，再运行检查。

请保留完整的 `dist` 文件夹，其中包含表格导入组件与验证材料。工具在浏览器中计算，无须安装程序或启动后台服务。

浏览器中的项目保存与访问入口有关。更换电脑、浏览器或使用入口前，请先导出项目，再在新入口导入。

## 当前功能

- 单场战斗及战斗、成长、资源和回访连接模拟。
- 目标与实际结果解释，包括完成周期、最长等待和未达标次数。
- 在允许的参数、锁定项和边界内搜索改法，支持一至三项联合修改及可选成长模板。
- 查看更多方案、同类变体，继续已有搜索；预览、应用和撤销修改。
- 使用已知单击、胜负、耗时、剩余生命、升级效果及费用核对真实算例。
- 对前后方案执行30、100或300对新编号验证，并保留配置、目标和计算状态以供复算。
- 项目保存、恢复、导入与导出。

## 源码与构建

| 路径 | 内容 |
| --- | --- |
| `dist/` | 可直接运行的完整工具及其引用材料 |
| `source/` | 界面源文件、模板、样式和构建脚本 |
| `source/connected-core/` | 战斗、成长、规则、诊断、搜索和配对验证核心 |
| `source/build-assets/` | 构建时需要的原始模型与默认配置 |
| `build.py` | 从本仓库独立重新构建，无须原电脑的目录 |

开发构建需要 Python 3.10或更高版本、Node.js 22或更高版本，不需要安装额外依赖：

```sh
python build.py
```

生成结果位于 `dist/`。如需单独输出以便对比：

```sh
python build.py --output outputs/rebuilt
```

也可以在本地通过固定地址访问工具：

```sh
python -m http.server 8000 --directory dist
```

然后打开 `http://localhost:8000/`。

第三方字体和表格导入组件的许可保留在 `source/字体许可/` 与 `source/表格导入/LICENSE.txt`。
