# 数值工坊

数值工坊是一款面向挂机、放置游戏的数值设计工具。把角色、敌人、升级、奖励和上线安排填进去，就能模拟从一场战斗到长期推关的过程，查看卡点，并比较调整方案。

**填我的游戏数据 → 选我要解决的问题 → 看结果和推荐**

它把战斗、购买和成长连在一起计算：攻击提升后能快多少、金币什么时候够买升级、下一次上线能过几关，都能沿着同一条模拟路线查看。

## 用它解决什么问题

| 设计时的问题 | 工具提供的结果 |
| --- | --- |
| 面板攻击很高，为什么还是打不过？ | 查看实际伤害、减伤、生存与逐击战斗记录，定位伤害不足、超时或角色死亡的原因。 |
| 提高攻击、攻速还是暴击更划算？ | 比较修改后的战斗耗时、失败次数和整条成长路线，查看各项改动的实际收益。 |
| 前期太简单，后期突然卡住，应该改哪里？ | 结合逐关推进、敌人成长、升级效果和价格，检查失衡出现的位置。 |
| 玩家一直在等，是缺金币还是上线安排造成的？ | 查看钱包、购买时点、最长未推进时间及每次回访进度，区分资源积累与时间安排。 |
| 想把通关周期调到目标区间，怎样改参数？ | 设置周期、等待等目标，锁定需要保留的参数，搜索并比较具体改法。 |
| 推荐方案换一批随机结果还有效吗？ | 对修改前后执行30、100或300对新编号验证，比较目标达成、通关耗时和战斗结果。 |

## 功能介绍

### 战斗模拟与伤害分析

配置角色和敌人的生命、伤害、攻击频率与战斗机制，先检查一场战斗，再把战斗接入完整成长过程。

- **五类伤害**：物理、火焰、冰霜、闪电和毒性，可分别配置并组合使用。
- **攻防机制**：暴击及暴击减免、护甲与固定或比例穿透、格挡、伤害增强、各类抗性与减抗、吸血及吸血减免、每秒回复。
- **伤害规则**：伤害范围、固定伤害、属性倍率、高级伤害公式、多段攻击，以及伤害取整方式。
- **状态与特殊效果**：持续伤害、护盾、条件效果、状态叠加与反应，可通过规则编辑器配置组合。
- **过程查看**：查看胜负、战斗耗时、剩余生命与逐击记录，追查伤害经过哪些计算才得到最终结果。

机制可以按项目需要独立开关；关闭时保留已填数据，方便比较不同机制组合。

### 成长、升级与资源经济

把每场战斗放进连续的推关过程，观察战斗能力与资源积累如何相互影响。

- 设置关卡数量、敌人成长、首领关卡、首通奖励和重复刷取奖励。
- 配置升级项目、作用属性、每级效果、价格、解锁条件与等级上限。
- 使用固定、线性、比例、分段或公式表达成长与价格规则。
- 配置固定收入、到账节拍、战斗期间收入及离线收益上限。
- 比较购买顺序与购买策略，查看金币如何转化为战斗能力和推关进度。

结果保留每笔购买的时间、项目、价格和钱包余额。遇到卡点时，可以回到当时的属性与资源状态，查看下一次升级还要等多久。

### 上线安排与长期推关

支持持续在线和定时回访两种推进方式，可设置上线时间、每次停留时长，以及离线期间的收入、购买和挑战行为。

运行后可以查看：

- **推进曲线**：什么时候通过了哪一关，哪里出现长时间停滞。
- **金币曲线**：资源如何积累，什么时候发生购买。
- **逐关记录**：到达与通过时间、战斗与等待、失败次数、关卡前后金币。
- **回访记录**：每次上线推进了多少关，资源和升级发生了什么变化。

这些记录可以用来比较“一天上线几次”“每次玩多久”和不同购买安排对完成周期的影响。

### 目标诊断与调整方案搜索

先设定希望达到的完成周期、最长等待等目标，再选择可以修改的参数、锁定项和数值边界。

工具会结合当前卡点搜索候选方案，并展示**改了什么、改善多少、付出什么代价，以及哪些目标还需要改善**。

- 支持一项、两项或三项参数联合修改。
- 可选择成长规则模板参与比较。
- 可以设置希望保留的方案数量，查看更多改法及同类数值变体。
- 继续已有搜索时复用已完成的计算，追加搜索预算。
- 推荐方案先预览，再应用；应用后可以撤销。
- 前后对照与历史记录保留各自的配置和目标，便于回看不同调整的效果。

除了“能不能过”，也能检查“虽然能过，但通关太慢”“等待过长”或“完成得太早”等节奏问题。

### 真实算例核对与批量验证

可以把游戏中已经知道的结果填入工具，与模拟计算逐项核对：

- 单次命中伤害。
- 整场胜负、耗时和剩余生命。
- 一次升级前后的属性变化。
- 实际升级费用。

核对结果会列出对应项目和数值差异，帮助调整输入或计算规则。

选定修改方案后，还可以执行**30、100或300对新编号验证**。修改前后使用匹配编号运行，汇总通关、目标达成、耗时中位数、P95及战斗结果，并保留逐次记录供复查。

### 数据导入、项目保存与导出

- 手动填写数据，或从内置《遗迹守卫》示例开始修改。
- 粘贴表格、导入表格数据，并确认字段对应关系与单位。
- 保存当前项目，恢复上次保存的配置。
- 导出游戏配置，用于备份、迁移或与他人交换方案。
- 导出完整模拟结果，保留配置、目标、编号和过程记录。
- 使用关卡数值表工具，生成基础关卡表、升级价格表及参数字段说明。

## 开始使用

1. 点击仓库上方 **Code → Download ZIP**，下载并解压。
2. 用 Chrome 或 Edge 打开 **`dist/index.html`**。
3. 选择“填写我的游戏”，从双方战斗数据开始；也可以载入《遗迹守卫》示例，先完整走一遍流程。
4. 检查单场战斗后，补充关卡、升级、收入和上线安排，运行整体模拟。
5. 查看卡点与目标差距，搜索改法，预览并比较结果后应用方案。

工具在浏览器中完成计算，无须安装程序或启动后台服务。使用时保留完整的 `dist` 文件夹。

更换电脑、浏览器或使用入口时，先导出项目，再在新入口导入即可。

## 开发与构建

| 路径 | 内容 |
| --- | --- |
| `dist/` | 可直接运行的工具及配套资源 |
| `source/` | 界面、模板、样式与构建脚本 |
| `source/connected-core/` | 战斗、成长、规则、诊断、搜索与配对验证核心 |
| `source/build-assets/` | 构建使用的模型与默认配置 |
| `build.py` | 独立构建入口 |

构建需要 Python 3.10或更高版本、Node.js 22或更高版本，无须安装额外依赖。

```sh
python build.py
```

生成结果位于 `dist/`。也可以指定单独的输出目录：

```sh
python build.py --output outputs/rebuilt
```

如需通过本地固定地址使用：

```sh
python -m http.server 8000 --directory dist
```

然后打开 `http://localhost:8000/`。

第三方字体和表格导入组件的许可见 `source/字体许可/` 与 `source/表格导入/LICENSE.txt`。
